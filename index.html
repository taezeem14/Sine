Engine Capabilities

Engineered for listeners who care about latency, fidelity, and control.

Every subsystem in Sine is built from first principles around native Android media pipelines — never wrapped webviews, never bloated ad SDKs.

Instant InnerTube Extraction

Resolves direct YouTube Opus (160 kbps) and AAC (128 kbps) streams via NewPipe-inspired InnerTube clients with automatic zemer-cipher n-sig unthrottling and Piped proxy failover.

ANDROID_VR · IOS · PIPED FAILOVER

True 6-Band Hardware DSP

Touch-draggable Bezier equalizer mapped via log-frequency interpolation to Android's native AudioEffect Equalizer (priority 1000), persisting seamlessly across Bluetooth & route switches.

25 OG PRESETS · LOG-FREQ MAPPING · ANTI-CLIP

Perceptual Cover Aurora & 120 FPS

A 36-bucket circular hue quantizer reads center-cropped album pixels (honoring monochrome artwork faithfully) to drive C∞ seamless fluid shaders and zero-blur GPU ambient halos.

36-BUCKET QUANTIZER · SWIPE-DOWN SHEET

BetterLyrics Karaoke & Story Cards

Millisecond-accurate word-sync karaoke, instant translation & romaji toggle, tap-to-seek lines, and exportable 4-line Lyric Story Cards saved straight to your Android Gallery.

LRCLIB · BETTERLYRICS · 4-LINE STORY EXPORT

SponsorBlock, Stems & Car Mode

Skip non-music intros, sponsors, and outros automatically. Isolate Vocals or Karaoke backing tracks, control playback from a 4×2 home widget, or switch to high-contrast Driving Mode.

SPONSORBLOCK · AI STEMS · 4×2 WIDGET

Sovereign Offline & JSON Backups

Download tracks with embedded ID3 tags and cover art to /Sine-Music/. Export or restore your entire library, individual playlists, and all 23 app settings as portable JSON files.

LOCAL STORAGE · UNIFIED JSON · PIN LOCK

System Architecture

Transparent end-to-end audio pipeline.

Every track flows directly from stream resolution to Media3 ExoPlayer and Android's hardware audio mixer — zero cloud middlemen, zero tracking beacons.

01 / RESOLVE

InnerTube + Cipher

Queries direct audio manifests with remote zemer-cipher n-sig unthrottling and instant Piped fallback.

02 / DECODE

Media3 ExoPlayer

Hardware Opus/AAC decoding with AudioOffload disabled so native Android DSP filters stay active.

03 / SHAPE

Hardware Equalizer

Log-frequency 6-band curve bound at priority 1000 with transparent logarithmic headroom protection.

04 / RENDER

120 FPS Flutter UI

Surgical Provider selectors, isolated RepaintBoundaries, and zero-blur radial aurora shaders.

Install on Android

Ready in under 30 seconds.

Sine is distributed directly as a signed universal Android APK from GitHub Releases — no Play Store account required.

1
Download the signed release APK

Grab Sine-v1.4.4.apk directly from the latest verified GitHub Release.

2
Install on Android 8.0 or newer

Open the APK in your file manager and allow "Install unknown apps" for your browser if prompted.

3
Or deploy directly via ADB

Updating an existing Sine install preserves your playlists, favorites, downloads, and EQ settings.

$adb install -r Sine-v1.4.4.apk
